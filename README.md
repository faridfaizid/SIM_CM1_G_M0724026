# Analisis Performa Penyewaan dan Pendapatan Toko DVD Sakila: Identifikasi Segmen Unggulan sebagai Dasar Pengambilan Keputusan Bisnis
Oleh : Farid Faiz (M0724026)

Analisis ini mengkaji struktur pendapatan dataset Sakila, yaitu database simulasi toko penyewaan DVD milik MySQL, melalui empat dimensi utama: kategori film, perbandingan kinerja antar toko, tren pendapatan bulanan, dan segmentasi nilai pelanggan. Dengan memanfaatkan bahasa pemrograman R dan pendekatan visualisasi data eksploratif, analisis berhasil mengidentifikasi pola musiman yang berulang, disparitas kinerja antar gerai, serta dominasi segmen pelanggan premium dalam kontribusi pendapatan. Temuan-temuan tersebut kemudian diterjemahkan ke dalam rekomendasi strategis yang actionable sebagai dasar pengambilan keputusan bisnis.
